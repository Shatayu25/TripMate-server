# TripMate - Backend API Server

This repository contains the PHP and MySQL backend REST API for the TripMate Hotel Booking Platform.

## Files Included
* **`db.php`**: Database connection configuration.
* **`rooms.php`**: GET endpoint to fetch room availability and details.
* **`bookings.php`**: POST endpoint to process new reservations.
* **`tripmate.sql`**: Database structure and mock data dump.
